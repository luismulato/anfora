## Resumen

ArtCraft es una suite creativa alternativa a Adobe, desarrollada desde cero en Rust de código abierto. Ofrece ejecución nativa multiplataforma, procesamiento estrictamente local y compatibilidad con agentes de IA mediante interfaces CLI, JSON y Model Context Protocol (MCP).

## Recursos clave mencionados

- **Repositorio VectorCraft:** https://github.com/storytold/vectorcraft
- **Protocolo de integración para agentes:** Model Context Protocol (MCP)

## Hallazgos

- **Ecosistema modular en Rust:** Comprende herramientas especializadas como PhotoCraft (edición de mapa de bits), VectorCraft (ilustración vectorial), FilmCraft (video), LightCraft (revelado RAW), EffectCraft (motion graphics) y DesignCraft (maquetación).
- **Rendimiento nativo y privacidad:** Compilado directamente para macOS, Windows y Linux (además de soporte WebAssembly en navegador), prescindiendo de envoltorios tipo Electron y procesando archivos de forma 100% local.
- **Preparado para automatización y agentes:** Incorpora arquitectura de control programático mediante CLI, mensajes JSON y servidores MCP, permitiendo a modelos de lenguaje y agentes de IA ejecutar herramientas y flujos de edición directamente.
