## Resumen

Guía rápida de extensiones y herramientas complementarias para Claude Code orientadas a resolver restricciones de consumo de tokens mediante fallbacks multimodelo gratuitos, incorporar persistencia contextual entre sesiones, auditar vulnerabilidades de código y habilitar extracción web sin costo de API.

## Recursos clave mencionados

- **Free LLM API:** Capa de enrutamiento y fallback multimodelo para evitar cortes por cuota de tokens.
- **x (Security Scanner / Pentesting):** Análisis de vulnerabilidades y agujeros de seguridad en el código generado.
- **Claude Mem:** Sistema de memoria persistente entre sesiones y proyectos locales.
- **Agent Reach:** Herramienta de navegación y lectura web sobre plataformas sociales (X, Reddit, LinkedIn, Instagram) sin consumo de API directa.
- **Claude Code Setup:** Asistente de configuración y recomendación de skills, subagentes y servidores MCP según el repositorio.

## Hallazgos

- **Gestión de límites de contexto/cuota:** El uso de interfaces de enrutamiento multimodelo permite continuar sesiones de codificación largas cuando se agotan los límites de la API principal de Anthropic.
- **Persistencia de contexto:** La integración de herramientas de memoria elimina la redundancia de tener que recontextualizar la arquitectura del proyecto al abrir nuevas sesiones en la CLI.
- **Automatización de entorno MCP:** La detección automática de dependencias acelera la vinculación de servidores Model Context Protocol (MCP) y subagentes adaptados al stack de trabajo.
