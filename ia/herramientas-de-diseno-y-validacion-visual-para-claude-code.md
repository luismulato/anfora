## Resumen

Ecosistema de cuatro herramientas y skills (Skill UI, Impeccable, UI/UX Pro Max y Playwright) integrables con Claude Code. Permiten superar el sesgo estético genérico del modelo mediante extracción de estilos, reglas tipográficas, sistemas de diseño contextuales y validación visual automatizada en navegador.

## Hallazgos

- Claude Code presenta una tendencia estadística a converger en patrones de diseño frontend repetitivos (degradados morados, tipografías estándar tipo Inter y tarjetas idénticas).
- **Skill UI:** Permite realizar ingeniería inversa a sitios web existentes extrayendo tokens de diseño (paletas, tipografía, espaciados) para replicar su estética estructurada.
- **Impeccable:** Skill de diseño frontend con reglas explícitas de anti-patrones para forzar criterios propios y evitar interfaces con apariencia genérica de IA.
- **UI/UX Pro Max:** Generador contextual de directrices visuales y combinaciones cromáticas adaptadas al tipo de aplicación (paneles, tiendas o landings).
- **Playwright:** Integración para ejecutar navegación *headless*, renderizado en navegador y detección de componentes rotos o desalineados antes de la revisión humana.
