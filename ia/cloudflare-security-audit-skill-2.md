## Resumen

Cloudflare lanzó Security Audit Skill, una herramienta diseñada para agentes como Claude Code y Codex. Permite orquestar análisis de arquitectura, detección automatizada de fallos y validación cruzada para mitigar falsos positivos en repositorios de código.

## Recursos clave mencionados

- Repositorio oficial: `cloudflare/security-audit-skill` en GitHub
- Modelos y herramientas compatibles: Claude Code, Codex

## Hallazgos

- **Mapeo inicial:** Examina la arquitectura del proyecto e identifica las superficies y zonas de mayor riesgo.
- **Detección y refutación:** Orquesta subagentes especializados; mientras unos buscan vulnerabilidades, otros intentan demostrar falsos positivos antes de darlas por válidas.
- **Reporte estructurado:** Categoriza los hallazgos en confirmados, pendientes de verificación manual y descartados.
