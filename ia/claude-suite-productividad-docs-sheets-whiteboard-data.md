## Resumen

Revisión técnica de las herramientas de productividad de Anthropic en Claude (Docs, Slides, Sheets, Whiteboard y Data). Evaluadas bajo el plan Pro con Claude Sonet, ofrecen edición directa, generación de gráficos y consultas SQL dinámicas para flujos de trabajo empresariales.

## Recursos clave mencionados

- **Video analizado:** [Claude lanzó su propio office. ¿Adiós Microsoft? (EDteam)](https://youtu.be/5w9SS8DMr1Y)
- **Herramientas de Anthropic:** Claude Docs, Claude Slides, Claude Sheets, Claude Whiteboard, Claude Data y capa de identidad visual Claude Design.
- **Integraciones y plataformas referenciadas:** Higgsfield (generación de imágenes vía Skills), BigQuery (conexión SQL en Claude Data), exportación a Word, PDF, Markdown, Google Docs, Notion, Monday, Asana, Miro y Lucidchart.

## Hallazgos

- **Claude Docs y Slides:** Permiten edición directa en la interfaz sin depender exclusivamente de nuevos prompts; Docs facilita conservar información clave de chats extensos evitando la pérdida por compactación de contexto, mientras Slides integra generación de imágenes mediante *skills* externas.
- **Claude Sheets:** Genera hojas de cálculo reales con fórmulas activas, formato condicional, manejo de monedas y dashboards integrados, permitiendo además importar archivos Excel y exportar hacia gestores como Monday o Asana.
- **Claude Whiteboard:** Lienzo infinito (zoom hasta 800%) con notas adhesivas, conectores dinámicos y dibujo vectorial asistido; utiliza un chat contextual local que delega investigaciones complejas al hilo principal de Claude y exporta a imagen, Miro o Lucidchart.
- **Claude Data:** Funciona como una herramienta de inteligencia de negocios (*BI*) conectada a fuentes de datos vivas o estáticas (como BigQuery) mediante consultas SQL editables, incorporando modos de visualización narrativa (*scrollytelling*).
- **Accesibilidad de modelo:** Todas las demostraciones de la suite operan bajo la suscripción Claude Pro ($20 USD) utilizando el modelo Sonet.
