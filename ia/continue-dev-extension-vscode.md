## Resumen

Continue es una herramienta de código abierto que funciona como asistente de IA para desarrollo, disponible como extensión de VS Code y JetBrains. Permite conectar API keys propias (OpenAI, Anthropic, Google Gemini, entre otros) o modelos locales autohospedados, en vez de depender de un proveedor fijo.

## Capacidades principales

- **Agent Mode:** trabajo colaborativo con IA sobre tareas de desarrollo, con acceso a herramientas.
- **Chat:** preguntas generales y explicación de código.
- **Edit Mode:** modifica fragmentos de código sin salir del archivo actual.
- **Autocomplete:** sugerencias de código inline mientras se escribe.
- **CLI (`cn`):** asistencia de IA desde la terminal.
- Configuración flexible de modelos, reglas y herramientas para crear, compartir y usar agentes de IA personalizados; funciona con o sin conexión (modelos autohospedados).
