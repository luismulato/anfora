## Resumen

Framework modular de código abierto desarrollado por Affaan Mustafa para Claude Code que expande el CLI estándar en un sistema multiagente autónomo con memoria intersesión, aprendizaje continuo de patrones de trabajo y cientos de habilidades preconfiguradas.

## Recursos clave mencionados

- Repositorio oficial en GitHub: https://github.com/affaan-m/ECC
- Comando de instalación directa vía terminal: `/plugin install ecc@ecc`
- Comando para registrar el marketplace en Claude Code: `/plugin marketplace add https://github.com/affaan-m/ECC`

## Hallazgos

- Convierte el entorno base de Claude Code en un equipo coordinado con roles especializados (planificación, arquitectura, seguridad y depuración de compilación).
- Implementa memoria persistente intersesión para mitigar la pérdida de contexto entre ejecuciones del CLI.
- Incluye mecanismos de aprendizaje continuo que identifican flujos recurrentes del historial del desarrollador para generar nuevas *skills* adaptativas.
- Provee integraciones directas con herramientas externas y protocolos MCP, incluyendo GitHub y Supabase.
