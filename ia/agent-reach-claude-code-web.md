## Resumen

Agent Reach es una herramienta CLI y skill de código abierto que dota a agentes como Claude Code de acceso de lectura a múltiples plataformas web (YouTube, Reddit, X/Twitter, GitHub) sin recurrir a APIs de pago ni claves externas.
