## Resumen

OpenWA es un gateway autoalojado de código abierto que permite enviar y recibir mensajes, multimedia y gestionar grupos en WhatsApp sin costos por mensaje, ofreciendo panel web, webhooks y compatibilidad con el protocolo MCP para agentes de IA.

## Hallazgos

- **Despliegue autónomo:** Permite levantar un endpoint propio de WhatsApp en infraestructura local o servidor privado sin intermediación ni cobros por mensaje de la API oficial de Meta.
- **Capacidades funcionales:** Soporta recepción y envío de texto, imágenes, video, administración de grupos, eventos salientes vía webhooks y gestión concurrente de múltiples sesiones.
- **Ecosistema de integración:** Cuenta con panel de administración web, conectores para n8n y Typebot, y soporte nativo para Model Context Protocol (MCP) orientado a agentes de IA.
- **Aislamiento de entorno:** Al operar sobre ingeniería inversa no oficial, se requiere el uso de números telefónicos dedicados para prevenir suspensiones en cuentas personales.
