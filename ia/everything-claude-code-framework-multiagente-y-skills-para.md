## Resumen

Framework para Claude Code desarrollado por Affan Mustafa que automatiza el ciclo de desarrollo mediante una red de 68 subagentes especializados, 292 skills preconfiguradas y memoria procedimental adaptativa capaz de extraer patrones de trabajo locales.

## Recursos clave mencionados

- **Proyecto / Repositorio:** `Everything Claude Code` por Affan Mustafa (destacado por superar 264.000 estrellas en GitHub).
- **Herramienta base:** Claude Code CLI (Anthropic) y compatibilidad cruzada con entornos de terminal / Codex en macOS, Linux y Windows.

## Hallazgos

- **Arquitectura multiagente delegada:** En lugar de interacción lineal usuario-modelo, el sistema opera con 68 subagentes con roles segmentados (planificación, revisión de código, seguridad y refactorización/debugging).
- **Ecosistema de habilidades y atajos:** Integra un catálogo de 292 skills ejecutables y más de 94 comandos directos para estandarizar flujos técnicos complejos.
- **Memoria y aprendizaje procedural:** Analiza el historial de trabajo del usuario, identifica patrones recurrentes de desarrollo y genera automáticamente nuevas skills adaptadas al estilo local.
- **Implementación multiplataforma:** Se incorpora como complemento dentro de la CLI mediante dos comandos de configuración directa.
