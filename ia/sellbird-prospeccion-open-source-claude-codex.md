## Resumen

Sellbird es una plataforma open source de prospección comercial que utiliza suscripciones existentes de Claude o ChatGPT/Codex para identificar empresas objetivo, localizar decisores, verificar correos, redactar mensajes personalizados y gestionar respuestas bajo aprobación humana local.

## Recursos clave mencionados

- Video analizado: https://www.youtube.com/watch?v=u7l4LlQ3xUY
- Repositorio / Proyecto: Sellbird (open source, ejecutado sobre Claude Code CLI o Codex CLI)

## Hallazgos

- Automatiza el embudo completo de prospección saliente: búsqueda de empresas, identificación de responsables de decisión y verificación de direcciones de correo electrónico.
- Utiliza los planes de suscripción existentes de Claude (Pro/Max) o ChatGPT (con Codex) sin requerir facturas adicionales por uso de API por token.
- Ejecuta las operaciones localmente en el equipo del usuario e incorpora supervisión humana por defecto: ningún correo o respuesta se envía sin aprobación previa explícita.
- Gestiona el seguimiento tras el envío leyendo respuestas entrantes y redactando borradores de contestación contextualizados.
