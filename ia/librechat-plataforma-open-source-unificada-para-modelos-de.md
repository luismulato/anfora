## Resumen

LibreChat es una interfaz web de código abierto y autoalojada que unifica múltiples proveedores de modelos de lenguaje (OpenAI, Anthropic, Google, DeepSeek, Mistral). Permite alternar modelos en tiempo real, crear agentes, usar MCP y ejecutar código manteniendo soberanía sobre la infraestructura.

## Hallazgos

- Unificación de proveedores comerciales y abiertos (OpenAI, Anthropic, Google Gemini, DeepSeek, Mistral) dentro de una misma interfaz web.
- Soporte para el protocolo MCP (Model Context Protocol) para conectar herramientas y servicios externos de forma modular.
- Capacidad de alternar entre distintos modelos de lenguaje dentro de un mismo hilo conversacional.
- Herramientas integradas para ejecución de código (Code Interpreter), búsqueda web nativa y gestión de archivos.
- Arquitectura *self-hosted* y *open source*, lo que permite desplegar la plataforma en servidores propios bajo Docker y conservar el control de datos e infraestructura.
