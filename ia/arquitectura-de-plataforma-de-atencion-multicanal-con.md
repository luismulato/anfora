## Resumen

Desarrollo integral con Claude Code de una plataforma omnicanal de soporte al cliente con IA que reemplaza flujos básicos de n8n. Integra WhatsApp oficial, webchat, Instagram, correo y telefonía junto a CRM, RAG documental y transferencia humana.

## Recursos clave mencionados

- **Video analizado:** https://youtube.com/shorts/zg1oTSMwAiQ
- **Herramienta de desarrollo asistido:** Claude Code (Anthropic CLI)
- **Plataforma de automatización previa:** n8n

## Hallazgos

- **Transición de automatización a plataforma:** Evolución desde flujos lineales de n8n hacia un software completo con bandeja de entrada estilo WhatsApp Web y CRM integrado.
- **Arquitectura multiagente por canal:** Implementación de agentes independientes especializados para WhatsApp (API oficial), widget web, Instagram Direct, correo electrónico y llamadas de voz.
- **RAG y base de conocimiento:** Ingesta de documentos propios para fundamentar las respuestas de los modelos en datos corporativos.
- **Orquestación operativa:** Soporte para agendamiento distribuido por empleado, modo de entrenamiento previo a despliegue, escalado/transferencia a agentes humanos y control de consumo de tokens.
- **Cumplimiento normativo:** Diseño estructurado con capas de seguridad y compatibilidad para la regulación europea de protección de datos (RGPD).
