## Resumen

Evaluación comparativa de cinco herramientas y agentes de inteligencia artificial para programación. Se pondera la integración en terminal, visibilidad del código, relación calidad-precio y potencia de los modelos, destacando Claude Code y Open Code sobre soluciones basadas en editor.

## Recursos clave mencionados

- **Claude Code:** Agente de Anthropic para terminal enfocado en tareas complejas y modelos avanzados.
- **Open Code:** Alternativa open source de ejecución local/terminal con soporte multimodelos.
- **Cursor:** Editor bifurcado optimizado para desarrollo interactivo con IA.
- **Codex (OpenAI):** Agente para ejecución de tareas delegadas y trabajo en paralelo.
- **GitHub Copilot / VS Code:** Extensión de asistencia y autocompletado en el entorno de desarrollo.

## Hallazgos

- **Evolución fuera del IDE:** Las mejores capacidades agénticas se están desplazando del editor de código tradicional hacia la terminal.
- **Transparencia en el flujo de trabajo:** Soluciones como Codex delegan tareas complejas en paralelo pero presentan desventajas al ocultar el proceso y la traza del código.
- **Eficiencia en costo/beneficio:** Las opciones de terminal de código abierto (Open Code) destacan como las más coste-eficientes frente a alternativas de suscripción o pago por token elevado como Claude Code.
