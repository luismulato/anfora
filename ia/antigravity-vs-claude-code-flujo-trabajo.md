## Resumen

Evaluación de rendimiento y costos entre Antigravity y Claude Code para desarrollo de software asistido por IA. Analiza la complementariedad operativa, optimización de presupuesto frente a planes premium y la ejecución asíncrona remota mediante Claude Code Dispatch.

## Recursos clave mencionados

- **Claude Code:** Herramienta CLI de desarrollo agéntico asistido por IA de Anthropic. Documentación: https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview
- **Antigravity:** Asistente y entorno optimizado para tareas de codificación rápida y directa.
- **Claude Code Dispatch:** Funcionalidad de ejecución y delegación de tareas en segundo plano/remoto. Documentación: https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview#dispatch
- **Graph Engineering (Ingeniería de Grafos en IA):** Marco conceptual para la estructuración de flujos agénticos interconectados frente al control lineal clásico. Referencia: https://en.wikipedia.org/wiki/Graph_(abstract_data_type)

## Hallazgos

- **Especialización por complejidad y velocidad:** Antigravity resulta más eficiente en tareas rápidas y directas; Claude Code destaca en resolución de problemas complejos y pipelines de testing exhaustivo, con un tiempo de ejecución superior.
- **Eficiencia de costos:** Combinar suscripciones de nivel estándar (20 USD mensuales en cada plataforma) ofrece mayor flexibilidad operativa que contratar una única suscripción premium de 100 USD.
- **Flujo remoto desacoplado:** El uso de Dispatch en Claude Code permite dejar la estación principal de trabajo procesando y enviar instrucciones o supervisar tareas desde dispositivos móviles en tiempo real.
- **Evolución metodológica:** Transición conceptual en los flujos de trabajo con agentes, superando el paradigma de bucles lineales (loops) hacia arquitecturas basadas en grafos de ejecución (graph engineering).
