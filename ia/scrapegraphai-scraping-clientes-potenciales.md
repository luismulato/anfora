## Resumen

Guía técnica breve sobre la implementación de ScrapeGraphAI junto a Claude y LLMs locales para raspar directorios públicos, estructurar datos de contacto comerciales en hojas de cálculo y programar pipelines de prospección automatizados sin costos de API.

## Recursos clave mencionados

- **Video analizado:** https://youtube.com/shorts/BmLlY_-NzqY
- **ScrapeGraphAI:** repositorio open source de scraping estructurado basado en grafos de IA — https://github.com/ScrapeGraphAI/Scrapegraph-ai
- **Claude / Claude Code:** asistente utilizado para la orquestación, instalación y ejecución de scripts.
- **Modelos de lenguaje locales:** soporte para ejecución local de inferencia para procesamiento de consultas sin coste.

## Hallazgos

- ScrapeGraphAI procesa listados y directorios web para extraer información pública estructurada (nombres, teléfonos, correos y contexto del negocio).
- Permite la ejecución completamente local utilizando modelos open-source para eliminar costos por consulta de inferencia.
- La configuración se puede automatizar mediante Claude proporcionando el enlace del repositorio para generar la instalación y programar tareas recurrentes.
