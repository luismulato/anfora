## Resumen

Prompt Motion es un repositorio web abierto que compila más de 230 animaciones vectoriales y motion graphics generados con Claude Opus. Cada recurso incluye el prompt exacto y el código subyacente para reproducir o personalizar animaciones para marcas y productos.

## Recursos clave mencionados

- **Video original:** https://www.youtube.com/watch?v=bHIMNW_4mlg
- **Sitio web catalogador:** https://prompt-motion.com (también accesible en https://promptmotion.org)
- **Modelo base:** Claude Opus (Anthropic)

## Hallazgos

- Recopilación de más de 230 casos de uso prácticos generados mediante generación de código y motion design con Claude.
- Clasificación de plantillas por categorías de producto: videos de lanzamiento, demostraciones de interfaces (UI), recorridos de aplicaciones móviles, gráficos animados y tipografía cinética.
- Posibilidad de bifurcar y adaptar el prompt y código fuente manteniendo consistencia en estilos de transición, timing y efectos sonoros para proyectos propios.

## Temas abordados en el video (orden cronológico)

- **[00:00:00] Presentación de Prompt Motion:** Introducción a la biblioteca comunitaria de motion graphics generados a partir de código con Claude.
- **[00:00:10] Categorías y catálogo de prompts:** Tipologías cubiertas en la plataforma (videos de producto, UI móvil, gráficos animados).
- **[00:00:19] Flujo de personalización:** Procedimiento para copiar prompts, ajustar parámetros de marca y reproducir las animaciones.
