## Resumen

Flujo de ingeniería asistida por IA para inicializar, desarrollar y someter aplicaciones móviles nativas a la App Store mediante Claude Code, utilizando React Native y Expo como stack multiplataforma unificado con testing local inmediato.

## Recursos clave mencionados

- **Video original:** https://www.youtube.com/watch?v=q_3XyLAlsfs
- **Herramienta principal:** Claude Code (Anthropic CLI / Agent Skills)
- **Framework base:** Expo (`create-expo-app`) y React Native
- **Comando de inicialización:**
  ```bash
  npx create-expo-app my-app

```

## Hallazgos

- **Stack multiplataforma unificado:** Uso de React Native junto con Expo para compilar hacia iOS y Android desde un único codebase gestionado por el agente CLI.

- **Ciclo de prueba y emulación rápida:** Previsualización en navegador web y prueba en dispositivos físicos en tiempo real mediante el escaneo de códigos QR con la app Expo Go (npx expo start).

- **Automatización de activos de publicación:** Empleo de skills de Claude para generar metadatos de tienda (título, descripción, palabras clave), configuración de certificados de distribución y generación de capturas de pantalla con formato para App Store Connect.

## Temas abordados en el video (orden cronológico)

- **[00:00:00] Configuración del entorno:** Instalación automatizada del framework React Native y Expo en la terminal mediante Claude Code.

- **[00:00:12] Construcción del MVP:** Generación de lógica de producto, bucles de retención y features avanzadas en el código base.

- **[00:00:24] Testing y validación:** Pruebas de interfaz en Chrome y ejecución en dispositivos físicos vía Expo QR.

- **[00:00:32] Preparación de metadatos y skills:** Redacción asistida de fichas técnicas, certificados y automatización de capturas para la App Store.

- **[00:00:41] Envío y distribución:** Someter la aplicación a revisión de Apple para su despliegue comercial.
