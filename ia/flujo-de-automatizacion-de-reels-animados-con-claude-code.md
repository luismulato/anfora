## Resumen

Configuración paso a paso de Claude Code en entorno local para automatizar la producción de reels animados mediante agentes. Permite generar guiones, locución, animaciones vectoriales y sincronización de subtítulos directamente sobre el sistema de archivos.

## Hallazgos

- **Entorno de ejecución local:** Requiere la aplicación de escritorio y acceso directo a una carpeta local designada para permitir lectura y escritura de assets y código por parte de Claude Code.
- **Configuración asistida de dependencias:** El agente analiza el sistema e instala las herramientas CLI y dependencias necesarias para síntesis de voz, generación gráfica y exportación de video.
- **Canalización integral (end-to-end):** A partir de un prompt temático de una sola línea, la herramienta genera el guion, sintetiza la voz, anima las escenas, alinea subtítulos y valida el resultado de forma iterativa antes de la entrega final.
- **Ciclo de retroalimentación en lenguaje natural:** Los ajustes sobre cortes o animaciones se gestionan mediante instrucciones directas como si fuera un editor de video humano.
