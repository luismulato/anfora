## Resumen

Alternativa de código abierto y ejecución local a Claude Design. Permite crear interfaces, presentaciones y prototipos interactivos usando modelos locales o APIs propias (BYOK), integrando decenas de sistemas de diseño preconfigurados y exportación multiformato.

## Recursos clave mencionados

- https://youtube.com/shorts/O1zei0WXHvY
- [Repositorio oficial de OpenDesign en GitHub](https://github.com/nexu-io/open-design)
- Soporte agéntico / CLI: Claude Code, Codex, Cursor, Gemini CLI, DeepSeek Harness
- Formatos de exportación admitidos: HTML, PDF, PPTX, ZIP, MP4

## Hallazgos

- Recrea el flujo de trabajo guiado por artefactos (*artifact-first loop*) de Claude Design sin muros de pago ni dependencias propietarias de servidor.
- Arquitectura agnóstica de modelo (*BYOK / Bring Your Own Key*): opera con suscripciones existentes, claves de API o LLMs ejecutados localmente sin consumo de créditos de plataforma.
- Incorpora sistemas de diseño predefinidos (más de 70 a 140 paquetes según la versión) basados en especificaciones `DESIGN.md` para garantizar coherencia visual desde la primera generación.
- Ofrece un lienzo interactivo (*canvas*) con previsualización en iframe aislado que permite refinamiento iterativo mediante lenguaje natural.
- Permite generar y exportar sitios web interactivos, prototipos de aplicaciones móviles, presentaciones (decks), dashboards y gráficos en movimiento hacia formatos estándar de producción.
