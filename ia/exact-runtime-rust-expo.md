## Resumen

Expo, empresa impulsora de React Native, lanzó Exact: un runtime en prealfa escrito en Rust para generar aplicaciones nativas multiplataforma desde una sola base de código sin React, WebViews ni Electron, diseñado para agentes de IA.

## Hallazgos

- **Arquitectura nativa sin React:** Exact está escrito en Rust y compila aplicaciones verdaderamente nativas para web, macOS, Windows, iOS y Android desde una única base de código, prescindiendo de React, WebViews y Electron.
- **Diseño orientado a agentes de IA:** Se concibe como un runtime en lugar de un framework tradicional para que agentes de IA construyan, ejecuten y prueben la aplicación completa mientras el desarrollador realiza la revisión.
- **Estado y contexto:** El proyecto se encuentra en fase prealfa (no apto para producción) y responde a una tendencia de equipos como Discord y Shopify que abandonan Electron y React Native.
