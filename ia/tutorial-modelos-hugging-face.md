## Resumen

Guía técnica para integrar modelos de [Hugging Face](https://huggingface.co/) mediante API serverless o ejecución local con GPU (Google Colab). Analiza pipelines de clasificación NLP y LLMs (Llama, Qwen), estructuración de salidas y evaluación de costos y privacidad corporativa.
