## Resumen

ECC es un framework de código abierto para entornos como Claude Code y Cursor que integra más de 60 agentes y 240 skills especializadas para orquestar diseño de arquitectura, generación de código, pentesting defensivo y pruebas automatizadas.

## Hallazgos

- **Especialización modular:** Agrupa 63 agentes especializados y 249 skills diseñadas para cubrir el ciclo completo de ingeniería de software mediante lenguaje natural.

- **Auditoría de seguridad autónoma:** Incluye un agente enfocado en seguridad ofensiva que ataca activamente el código base del proyecto para detectar y parchear vulnerabilidades antes del despliegue.

- **Flujo guiado por fases:** Soporta delegación completa para diseño de arquitectura, generación de código en múltiples lenguajes y suite de testing automatizado hasta alcanzar un 80% de cobertura.

- **Integración con arneses de IA:** Compatible de manera directa con editores e interfaces de agentes como Claude Code, Cursor y OpenAI Codex.
