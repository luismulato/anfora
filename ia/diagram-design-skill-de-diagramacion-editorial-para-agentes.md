## Resumen

Skill de código abierto para agentes de codificación (Claude Code, Cursor, Codex) que genera diagramas editoriales vectoriales directamente como archivos HTML y SVG autocontenidos. Reemplaza herramientas manuales y evita sintaxis tipo Mermaid mediante soporte para 44 tipologías personalizables.

## Recursos clave mencionados

- **Video original:** https://youtube.com/shorts/E8f-zbUcHnk
- **Repositorio oficial (GitHub):** https://github.com/cathrynlavery/diagram-design
- **Comando de instalación (skills CLI):** `npx skills add cathrynlavery/diagram-design`
- **Comando de instalación (Pi CLI):** `pi install https://github.com/cathrynlavery/diagram-design`

## Hallazgos

- **Salida independiente:** Genera un único archivo autocontenido en HTML con gráficos vectoriales SVG embebidos, ejecutable localmente sin dependencias externas.
- **Amplia cobertura de formatos:** Soporta 44 tipos de esquemas técnicos y organizacionales (diagramas de arquitectura, secuencias, flujos, Gantt, matrices, organigramas, grafos de dependencia y mapas de Wardley).
- **Consistencia visual y de marca:** Permite adaptar automáticamente paletas cromáticas y familias tipográficas a partir de pautas de diseño o inspección web.
- **Compatibilidad con agentes CLI:** Integración nativa a través del estándar de Agent Skills en plataformas de asistencia de código como Claude Code, Codex, Cursor y Pi.
