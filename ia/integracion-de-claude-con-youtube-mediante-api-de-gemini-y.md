## Resumen

Método para capacitar a Claude extrayendo transcripciones y contenido multimodal de YouTube mediante la API gratuita de Gemini. La propuesta automatiza la conversión del aprendizaje de videos en nuevas skills y agentes especializados dentro del ecosistema de Claude.

## Recursos clave mencionados

- [Video original en YouTube](https://www.youtube.com/shorts/RDWPjBqRrro)
- Google AI Studio (obtención de API key gratuita de Gemini)
- Sistema de Skills para Claude / Claude Code

## Hallazgos

- Se requiere una configuración inicial de tres componentes: una skill de extracción para Claude, una API key de Gemini (Google AI Studio) y una skill generadora de agentes.
- Aprovecha la capacidad nativa multimodal de Gemini para procesar video y audio de YouTube, transfiriendo ese contexto procesado a Claude.
- Permite la síntesis estructurada de listas de reproducción o videos temáticos para entrenar agentes verticales (ej. copywriting, community management, análisis técnico).

## Temas abordados en el video (orden cronológico)

- **[00:00:00] Introducción al pipeline:** Explicación del flujo para capacitar a Claude con videos de YouTube y generar skills automáticas.
- **[00:00:09] Componente 1 (Skill de ingesta):** Instalación de la skill que habilita a Claude a extraer contenido, marcas de tiempo e información completa de YouTube.
- **[00:00:26] Componente 2 (API de Gemini):** Conexión con Google AI Studio para delegar el análisis audiovisual nativo en Gemini.
- **[00:00:36] Componente 3 (Generador de agentes):** Automatización que convierte el conocimiento adquirido de los videos en nuevas skills y agentes especializados.
