## Resumen

Meta liberó Astryx bajo licencia MIT como sistema de diseño open source. Incluye más de 150 componentes React, plantillas completas, soporte para modo oscuro, temas personalizables y optimización nativa para agentes de codificación como Claude Code y Codex.

- Video analizado: https://www.youtube.com/watch?v=AGoC0_DCVts

- Sitio oficial de documentación: astryx.aiwmeta.com

## Hallazgos

- **Catálogo integral en React:** Incluye más de 150 componentes preconstruidos y plantillas listas para producción bajo licencia MIT.
- **Personalización y estilos:** Incorpora soporte nativo para modo oscuro, propiedades CSS personalizadas (*custom properties*) y configuración visual mediante un *playground* interactivo.
- **Optimización para agentes (Agent-ready):** Diseñado e integrado específicamente para flujos de trabajo asistidos por agentes de desarrollo como Claude Code y Codex, incluyendo plugins dedicados en el repositorio.
