## Resumen

Meta lanza **Muse Code** (en beta), un agente para terminal con el modelo **Muse Spark 1.2** que compite con Claude Code y Codex ejecutando subagentes en paralelo para escribir y depurar código vía API.

## Recursos clave mencionados

- **Página oficial del modelo (OpenRouter API & Benchmarks):** [Meta Muse Spark 1.2 en OpenRouter](https://openrouter.ai/meta/muse-spark-1.2)
- **Instalación rápida en terminal (macOS / Linux):** `curl -fsSL https://dev.meta.ai/install.sh | bash`

## Temas abordados en el video (orden cronológico)

- **[00:00:00] Presentación y contexto:** Anuncio del lanzamiento de Muse Code por parte de Meta en el mercado de agentes de programación (Claude Code y Codex).
- **[00:00:06] Interfaz y modelo base:** Explicación de que funciona desde la terminal y utiliza el modelo Muse Spark 1.2.
- **[00:00:13] Capacidades principales:** Funcionalidades para escribir, depurar código, gestionar tareas de larga duración y coordinar subagentes en paralelo.
- **[00:00:23] Disponibilidad y modelo de costes:** Estado en versión beta y esquema de precios basado en pago por uso mediante API.
