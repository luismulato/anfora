## Resumen

AWS Emulator es un emulador oficial, gratuito y de código abierto escrito en Rust que ejecuta servicios como S3, Lambda, DynamoDB y SQS localmente en Windows, macOS y Linux, eliminando costos de nube durante pruebas y prototipado.

## Recursos clave mencionados

- Video analizado: http://www.youtube.com/watch?v=1tO4QmpzQ1E
- Repositorio oficial en GitHub: https://github.com/aws/aws-emulator

## Hallazgos

- Permite emular servicios de Amazon Web Services (como S3, Lambda, DynamoDB y SQS) al 100 % en entorno local (`localhost`) sin requerir una cuenta de AWS ni generar facturación.
- Está desarrollado en Rust bajo licencia de dominio público CC0-1.0 y ofrece soporte multiplataforma nativo para Windows, macOS y Linux.
- Resulta idóneo para ejecutar pruebas unitarias, tests de integración y validación rápida de prototipos antes de desplegar en producción.
