## Resumen

Compilación técnica de atajos de teclado esenciales en Visual Studio Code y editores derivados para optimizar la manipulación de líneas, la selección múltiple concurrente y el refactorizado semántico de variables sin recurrir al portapapeles ni a búsquedas globales.

## Hallazgos

- `Alt + Flecha Arriba/Abajo`: Desplaza la línea o bloque de código activo verticalmente sin necesidad de cortar y pegar.
- `Ctrl + D`: Añade a la selección concurrente la siguiente coincidencia idéntica del texto seleccionado para edición simultánea.
- `F2`: Ejecuta el renombrado semántico de identificadores/variables a nivel de proyecto mediante el Language Server Protocol, evitando reemplazos por texto plano.
- `Alt + Clic`: Instancia múltiples cursores en posiciones arbitrarias del documento para escritura y edición paralela.
- `Cmd + Clic` (macOS): Abre el enlace bajo el cursor al hacer clic sobre él en un archivo Markdown.
