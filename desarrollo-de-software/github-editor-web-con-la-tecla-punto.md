## Resumen

GitHub integra un editor basado en Visual Studio Code para la web accesible presionando la tecla punto (`.`) en cualquier repositorio. Permite explorar y editar código directamente en el navegador sin instalaciones locales.

## Hallazgos

- Al presionar la tecla `.` dentro de cualquier repositorio público en GitHub, la URL redirige automáticamente al entorno web de Visual Studio Code (`github.dev` / `vscode.dev`).
- La herramienta carga la estructura de archivos y extensiones compatibles sin requerir instalación local de dependencias o editores.
- Facilita la navegación rápida, lectura y edición ligera de código directamente desde el navegador.
